CV KREATIF - TEMPLATE WEBSITE OFFLINE

Cara menjalankan:
1. Ekstrak folder cv-bootstrap.
2. Buka index.html menggunakan browser (Chrome/Edge/Firefox).
3. Edit nama, deskripsi, kontak, pendidikan, pengalaman, dan keahlian di index.html.
4. Untuk menampilkan foto, letakkan foto kamu di assets/images/ dengan nama foto-profil.jpg.
5. Ubah email dan nomor telepon contoh menjadi data milikmu.

Catatan penting:
Folder assets/css/bootstrap.min.css dan assets/js/bootstrap.bundle.min.js dalam paket ini adalah subset kompatibel Bootstrap yang dibuat lokal agar template bisa dibuka offline dan layout responsif. Keduanya BUKAN distribusi resmi Bootstrap. Jika dosen mensyaratkan framework Bootstrap resmi, unduh paket Bootstrap 5 dari getbootstrap.com saat terhubung internet, lalu ganti kedua file tersebut dengan bootstrap.min.css dan bootstrap.bundle.min.js resmi. Pertahankan link lokal di index.html agar website tetap offline setelah file resmi disimpan.
